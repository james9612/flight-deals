# 飛行便宜｜機票優惠情報站

這是以台灣出發優惠為主的前端原型，區分航空公司促銷與旅行社計畫／清艙票。

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可；目前不需要安裝套件或啟動伺服器。

## 專案結構

- `index.html`：頁面結構
- `styles/site.css`：視覺樣式
- `scripts/app.js`：篩選互動與原型資料

## 資料狀態

目前卡片包含公開搜尋參考價與一筆公開計畫票範例，均不能視為保留票價或保證庫存。正式資料接入前，需確認來源授權、資料更新頻率和可公開欄位。建議每筆優惠保存來源名稱與連結、票種、出發地、目的地、固定出發日期、行程天數、價格、行李／改退條件、最後確認時間及有效狀態。

## 下一階段

1. 選定第一批要追蹤的航空公司與旅行社公開優惠來源。
2. 確認東南旅遊 API 和台灣虎航旅行社 API 的合作資格及資料涵蓋範圍；不能假設一般航班 API 會提供旅行社團體清艙庫存。
3. 建立人工審核／上架流程，再視合作資料與流量規模決定是否加入後端和自動同步。

## 第一批票源

`data/sources.json` 是來源目錄的資料檔，`sources.html` 可在瀏覽器查看。首輪建議人工試行：

- 航空促銷與旅行社公開票價：台灣虎航、Peach 樂桃、可樂旅遊、易遊網、易飛網。易遊網常見優惠碼可能受 APP、會員、信用卡和出發日期限制；易飛網首頁有航空活動精選，需點入確認含稅情況。
- 計畫／清艙票：飛遊網清艙分類、旅行社公開商品頁（如東森購物的旅行社計畫票商品）。
- 合作/API：東南開放平台、虎航 Navitaire API 都先列為「需合作核准」；易飛網另有聯盟行銷平台，但需確認是否提供商品 feed/API。導購合作不等同即時票價或清艙庫存存取。不假設上述 API 有清艙團體票庫存。

上架前人工確認票價、有效日期、剩餘名額（若公開）、行李與改退條件、原始連結及確認時間。找不到或無法確認的欄位要明確標示，不推測補值。

## 真實優惠資料

`data/deals.json` 是第一批公開票價資料。每筆保存價格類型、原始來源連結與最後確認日期；前端目前同步保留同一批資料於 `scripts/app.js`，讓專案可直接以本機檔案開啟。首批包含易遊網公開航班搜尋的參考價，以及雄獅旅遊公開商品頁的固定日期計畫票；確認日為 2026-10-24，僅作查價參考，不能視為保證庫存或最終結帳價。

## 多城市行程

優惠搜尋區支援依出發地、目的地、出發日與回程日篩選已整理的票源。多城市規劃器可輸入 2–4 段行程，並選擇偏好同一張聯程票或也接受分段購票；目前只產生搜尋條件草稿，沒有即時航班或價格。

接入具多航段搜尋能力的票價 API 後，應把「同一張票涵蓋所有航段」與「每段分開購買」分開呈現。前者需由供應商回傳同一筆完整 offer；後者要明確標示分開開票及自行轉機風險。
