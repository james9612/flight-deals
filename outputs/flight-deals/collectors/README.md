# 自動優惠蒐集器

這個資料夾放各票源的自動蒐集器。蒐集器不經由人工上架表單，而是定期讀取公開頁面、轉成統一資料，再寫入 `data/collected/`。

## 第一個來源：飛遊網清艙機票

`collect-plynet.mjs` 會開啟飛遊網首頁的「特價清艙」日曆，逐筆讀取公開卡片與詳情視窗，整理出：

- 商品代碼與原始來源網址
- 出發／回程日期、天數、出發地與目的地
- 航空公司與航班資訊
- 含稅價格、行李與改退規則
- 擷取時間

第一次部署前，在執行環境安裝 Playwright：

```sh
npm install playwright
npx playwright install chromium
node collectors/collect-plynet.mjs
```

建議每天執行一次；出發日前 14 天可改為每 4 小時。正式環境要接一個合併程序：以商品代碼優先去重、保留最後確認時間，過期或來源消失的項目改為下架而非直接刪除。

## 上架規則

1. 僅收錄公開頁面實際顯示的資料。
2. 沒有出發日、回程日或價格的項目留在待補資料，不顯示於前台。
3. 前台保留原始來源連結與擷取時間。
4. 來源頁顯示「不可改期／不可退票」時，前台同步顯示該限制。
